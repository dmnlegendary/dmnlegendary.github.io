Technical Skills & Competencies

My technical stack is built around a strong foundation in Artificial Intelligence and Software Engineering. I focus on developing scalable backend architectures, training machine learning models, and ensuring seamless deployment through cloud infrastructure and version control tools.

Programming Languages

  • Python: Primary language for AI/ML, data analysis, and backend API integration.
  • C & Java: Object-oriented programming, data structures, and systems-level logic.
  • Lua: Scripting and lightweight integrations.

Frameworks & Libraries

  • Keras & Scikit-learn: Building, training, and evaluating deep learning and traditional machine learning models.
  • Jupyter Notebooks: Rapid algorithm prototyping, data visualization, and quantitative analysis.

Tools & Infrastructure

  • Cloud & DevOps: Azure deployment, Git version control, and GitHub Actions for continuous integration.
  • Environments: Linux/Bash scripting for server management and automation.
  • Engines: Unity for interactive environments and simulations.

Core Competencies

Beyond individual languages or tools, my engineering approach is defined by these core areas of expertise:

  • Artificial Intelligence & Machine Learning: Designing predictive models and intelligent, context-aware agents.
  • Software Development: Architecting robust backend logic for complex systems, ensuring high reliability and low latency.
  • RESTful API Integration: Seamlessly connecting third-party services (such as environmental data or LLMs) into unified applications.
  • Cloud Computing: Understanding the principles of deploying and managing applications in scalable cloud environments.
